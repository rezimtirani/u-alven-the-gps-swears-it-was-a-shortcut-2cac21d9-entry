The GPS's own excuse for sending the driver down the wrong road: it was never the wrong way, it was the scenic way — and the scenery is a ditch.

> I didn't send you the wrong way — I sent you the scenic way. The scenery is a ditch.

## How it works

`main.py` (Python 3 standard library only) writes the excuse to `$MAKEFUN_OUTPUT_DIR/entry.txt`, checked first against the competition gate: 1 to 200 characters of UTF-8 text, a single line, no setup, no dialogue tags.

```sh
python3 main.py
```
